# SyncSpace

SyncSpace is a collaborative workspace platform where users can create workspaces, manage members, upload files, and collaborate efficiently.

## Features

- JWT Authentication
- User Registration & Login
- Workspace Creation & Management
- Member Management
- Role-Based Access Control
- Secure REST APIs
- Spring Security Integration
- File Upload Support
- Version Control System (Planned)

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- JPA / Hibernate
- Maven
